# ChallanAI (EmbroideryOS) - Frontend Mobile-First PWA

This directory hosts the Next.js (App Router, TypeScript, Tailwind CSS, Lucide Icons) mobile-first application.

## 4-Tab Blueprint:
1. **💬 WhatsApp AI Bot (`/`)**: Authentic WhatsApp chat simulator with challan photo upload, Gujarati voice/text queries, quick-test sample cards, and AI confirmation modals.
2. **📦 બાકી માલ - Pending Lots (`/pending`)**: Real-time lot reconciliation progress bars (Inward vs. Outward vs. Kasar) with 1-click partial delivery logging.
3. **🧮 સ્ટીચ ભાવ - Stitch Rate & Shift Tracker (`/calculator`)**: Instant Stitch-to-Profit pricing calculator + Machine LCD stitch counter logger for Day/Night shifts.
4. **📄 પાર્ટી ખાતું - Party Ledger (`/ledger`)**: Photo-backed Party statement with original paper challan thumbnails, A4 printable PDF layout, and Tally Prime CSV export.

Includes instant **1-Click Gujarati (ગુજરાતી) / English toggle** across all tabs.
